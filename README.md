# La Grandezza Events

A luxury event planning platform with a full-featured admin dashboard, online booking, portfolio management, and client testimonials.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Framer Motion
- Recharts
- React Router v6

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Luxury public-facing website (home, services, packages, portfolio, contact, booking)
- Password-protected admin dashboard
- Light / dark mode
- M-Pesa & Stripe payment flow
- User accounts and testimonials
- Fully responsive
